# Changelog

## 0.1.0-beta.1 - 2026-09-23

### Added

- Add 193 VPC commands covering networks, subnets, security groups, interfaces, virtual IPs, routing, ACLs, peering, DHCP option sets, prefix lists, flow logs, traffic mirrors, network path analysis, and layer 2 and IP gateways.
- Include captured official examples, Simplified Chinese and English help, typed request inputs, documented conditional requirements, deprecation warnings, mutation confirmation, and eight bounded waiters using documented states and exact resource identities.
- Require core 0.5.0 or later for explicit response contracts, conditional alternatives, and identity-selected waiters.

### Known limitations

- Missing lifecycle evidence and request constraints that depend on undeclared inputs, resource-pool class, or nested mutually exclusive inputs remain recorded in the coverage inventory. Address-allocation exclusivity and batch partial-success behaviour remain documented in command help.
- Preserve original upstream examples alongside recorded punctuation repairs; no response values are invented.
