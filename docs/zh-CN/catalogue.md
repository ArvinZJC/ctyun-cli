# 产品插件目录

[项目首页](../../README.md) · [English](../en/catalogue.md)

当前提供 97 个插件、7,751 条命令，覆盖自研池（一类节点）的客户侧 API。部分产品或接口因缺少可核实的公开服务地址、请求或响应说明而暂不支持；合营池和其他范围外接口不纳入支持。覆盖情况以已核实的官方文档为依据，不代表所有接口均已通过真实云环境验证。

核心 `0.5.2` 支持本目录中的所有插件，其中 46 个插件声明的核心兼容范围为 `>=0.5.1 <1.0.0`。插件版本和发布通道仍独立于核心版本维护。

使用以下插件时，请留意各自的适用范围、配置要求和功能限制：

- 网关：`api-gateway` 对应资源与订单代理接口目录，仅支持其中的自研池的客户侧接口；`cloud-native-api-gateway` 管理独立的云原生 API 网关实例，`mse` 中的网关命令属于微服务引擎。三者的服务地址和接口契约不同。

- 网络：`nat` 管理公网 NAT 网关，`private-nat` 管理私网 NAT 网关。暂不支持旧版 EIP 网络查询。
- RDS：暂不支持 6 个 PostgreSQL 下载或导出接口。已下线的 MySQL 跨地域备份目标地域查询命令仍保留弃用警告，但无法在线调用。
- Redis：`redis` 基于官方标为“2023-10-18 II类资源池”的 API 目录（`vid=270`）；该标签是 Redis 产品的目录分类，不代表本项目所排除的合营池（二类节点）。历史接口位于 `ctyun redis legacy`；要求核心版本 `>=0.5.1 <1.0.0`。所有命令均提供离线响应夹具，部分生命周期操作暂不支持等待完成。
- MongoDB：`mongodb` 的旧版接口位于 `ctyun mongodb v1`；要求核心版本 `>=0.5.1 <1.0.0`。三个导出 API 因二进制响应契约不明确暂未提供；所有已支持命令均提供离线响应夹具。
- 存储：`media-storage` 和 `classic-object-storage` 的 `native` 命令使用独立的存储凭证，详见[存储鉴权与文件传输](storage.md)。媒体存储 OpenAPI 网关适用于西藏资源池 1 区。
- 云助手：插件保留了 `ctyun cloud-assistant command run`。[目录复核](../../openapi-catalogs/official-review.json)未能从公开接口详情页取得正文，该次复核未测试接口的在线可用性。
