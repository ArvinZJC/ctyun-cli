# Product plugin catalogue

[Project home](../../README-EN.md) · [简体中文](../zh-CN/catalogue.md)

The CLI provides 97 plugins and 7,751 commands for customer-side APIs in self-operated resource pools. Some products or APIs remain unsupported because their public endpoints or request and response contracts cannot be verified. Joint-operation pools and other out-of-scope APIs are excluded. Coverage is based on verified official documentation and does not imply that every API has been tested against a live cloud environment.

Core `0.5.2` supports all plugins in this catalogue. Of these, 46 declare the range `>=0.5.1 <1.0.0`. Plugin versions and release channels remain independent of the core version.

When using the following plugins, note their scope, configuration requirements, and limitations:

- Gateways: `api-gateway` covers the resource and order proxy catalogue for self-operated customer-side usage. `cloud-native-api-gateway` manages standalone cloud-native API gateway instances; gateway commands in `mse` belong to Microservice Engine. These use different endpoints and API contracts.

- Networking: `nat` manages public NAT gateways; `private-nat` manages private NAT gateways. The legacy EIP network query is not yet supported.
- RDS: six PostgreSQL download/export APIs are not yet supported. The retired MySQL cross-region backup destination query remains listed with a deprecation warning but is unavailable online.
- Redis: `redis` is based on the API catalogue officially labelled “2023-10-18 II类资源池” (`vid=270`). This Redis catalogue label does not mean the joint-operation pools (second-class nodes) excluded by this project. Historical APIs are under `ctyun redis legacy`; it requires core `>=0.5.1 <1.0.0`. All commands include offline response fixtures; waiting for completion is not yet supported for some lifecycle operations.
- MongoDB: older APIs are under `ctyun mongodb v1`; the plugin requires core `>=0.5.1 <1.0.0`. Three export APIs remain unavailable because their binary response contracts are unclear. All supported commands include offline response fixtures.
- Storage: `media-storage` and `classic-object-storage` commands under `native` use separate storage credentials. See [Storage authentication and file transfers](storage.md). The media-storage OpenAPI gateway applies to Tibet resource pool 1.
- Cloud Assistant: the plugin retains `ctyun cloud-assistant command run`. The [catalogue review](../../openapi-catalogs/official-review.json) found no public detail page content for the operation. Its live availability was not tested in that review.
